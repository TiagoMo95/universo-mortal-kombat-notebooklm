# 🐉 Caderno Temático — Universo Mortal Kombat | NotebookLM

## 📚 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio da DIO com foco na utilização de Inteligência Artificial como ferramenta de aprendizagem ativa.

O tema escolhido foi o universo de Mortal Kombat, uma das franquias mais influentes da história dos videogames, conhecida por sua narrativa complexa, reinos, clãs, personagens icônicos e linhas temporais alternativas.

O objetivo deste caderno temático foi utilizar o NotebookLM para organizar conteúdos, criar resumos inteligentes, estruturar conhecimentos e testar estratégias de engenharia de prompts utilizando fontes abertas sobre a franquia.

---

# 🎯 Objetivos de Estudo

- Compreender a cronologia principal de Mortal Kombat;
- Estudar os reinos existentes no universo da franquia;
- Identificar os principais personagens e suas motivações;
- Analisar a evolução da narrativa ao longo dos jogos;
- Utilizar IA para sintetizar informações complexas;
- Praticar engenharia de prompts e curadoria de conteúdo.
